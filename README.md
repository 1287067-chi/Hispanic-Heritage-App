# Hispanic Heritage Historical Data Explorer

An interactive Streamlit web application that retrieves authentic historical socio-economic indicators for Latin American nations from the World Bank API, fits centered polynomial models, and provides interactive curricular insights across Algebra 2, Precalculus, and Calculus levels.

---

## 1. Local Setup & Execution

### Prerequisites
- Python 3.9, 3.10, or 3.11 installed on your system.

### Steps
1. Clone or download this repository into a local folder.
2. Open a terminal/command prompt in the directory.
